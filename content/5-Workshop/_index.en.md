# CAMPUSMEET — AWS SERVERLESS HANDS-ON WORKSHOP

This 2–4 hour workshop guides learners through inspecting, validating, and conditionally deploying CampusMeet. The core lab covers M1–M2 capabilities supported by current code; M3–M5 are explicitly marked partial, optional, or architecture walkthroughs.

{{% notice warning %}}
The workshop can incur AWS charges. Only the deployment owner should deploy shared dev resources; do not use a production account, commit credentials, or skip 5.10 Cleanup.
{{% /notice %}}
